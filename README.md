# BLACK CUTS · barbería (proyecto demo)

Web de barbería con **reserva de turnos** y **agenda del barbero**, hecha con HTML, CSS y JavaScript puro.

- El cliente elige servicio, barbero, día y hora (las horas ocupadas salen tachadas).
- Al confirmar recibe un ticket de turno y lo envía por WhatsApp.
- El dueño ve la agenda del día por barbero, cuántos turnos hay y el ingreso estimado.
- Muestra "Abierto ahora / Cerrado" según la hora real.

Configuración (número de WhatsApp, servicios, barberos y horario): al inicio de `app.js`.

Proyecto demo hecho por **tihago.dev** (Tihago Cueva).
